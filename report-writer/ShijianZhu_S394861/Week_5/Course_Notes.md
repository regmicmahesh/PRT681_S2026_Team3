# Week 5 Course Notes

## Topic 1 — Audience, purpose and scope

- Audience determines the language, detail and format used in a report.
- Purpose explains the decision or action the report should support.
- Scope sets clear boundaries so the report stays relevant and manageable.

## Topic 2 — Report structure

- An executive summary gives the reader the main message quickly.
- Findings present the important facts identified through research or analysis.
- Recommendations should be practical and clearly linked to the findings.

## Topic 3 — Source and data quality

- Reliable sources should be relevant, current and produced by a credible authority.
- Missing or conflicting information should be checked before conclusions are written.
- Any unresolved assumptions or limitations should be stated clearly in the report.

## Topic 4 — Visual reporting

- Line charts are useful for trends, while bar charts are useful for comparisons.
- Every visual needs a clear title, readable label and appropriate unit.
- Colours and layout should support accessibility and avoid distracting the reader.

## Topic 5 — Power BI and SSRS

- Power BI is suited to interactive dashboards, filters and visual exploration.
- SSRS is suited to detailed, printable and paginated operational reports.
- The reporting tool should be selected according to the audience and output requirement.

## Topic 6 — Quality checking and version control

- Proofreading should check accuracy, clarity, grammar and consistent formatting.
- File names and folders should make the latest approved document easy to find.
- Meaningful Git commits create a clear history of important document changes.
