# SQL, Power BI and SSRS Notes

## SQL and PostgreSQL

- **SQL:** a language used to retrieve and summarise database information.
- **PostgreSQL:** a relational database system that stores report data.
- **pgAdmin:** a graphical tool for managing PostgreSQL and running queries.
- **SELECT:** chooses the columns required for a report.
- **WHERE:** filters records.
- **ORDER BY:** sorts results.
- **GROUP BY:** groups records for totals, counts or averages.
- **JOIN:** combines related data from different tables.

Before using query results, check for null values, duplicates and unexpected totals.

## Power BI

Power BI is useful for interactive dashboards. Important parts include data connections, table relationships, measures, KPIs, charts, slicers and filters.

## SSRS

SSRS is useful for structured and paginated reports. Important terms include:

- **Data source:** the connection to the database.
- **Dataset:** the query result used by the report.
- **Parameter:** a value used to filter the report.
- **Tablix:** a report layout for tables and grouped data.
- **Paginated report:** a fixed-layout report designed for printing or exporting.

## Power BI compared with SSRS

| Tool | Best use |
|---|---|
| Power BI | Interactive dashboards and visual analysis |
| SSRS | Detailed, printable and paginated reports |

The correct tool depends on the audience, purpose and required output format.
