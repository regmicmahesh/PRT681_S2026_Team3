# Task interpretation

This folder addresses **ROLE BASED TASKS — Report Writer — Week 2: Dashboarding & Automation**. It is separate from the earlier general programming activities and the Individual Project Canvas.

The supplied practice asks for an interactive Power BI version of an Excel report, at least three DAX measures, and one repetitive Excel task automated with VBA. YTD sales and percentage change are examples. The supplied text does not require a sales topic or a lecturer-provided dataset, so this exercise first creates an Excel report from official NT data and then provides its Power BI counterpart.

The five listed course topics are addressed in Course_Notes.md. Those notes do not certify completion of the courses. The Tableau section is a comparison plan; the Fabric section is introductory study material. Neither has been presented as a deployed system.

The SharePoint page requires university access and could not be independently retrieved in this environment. This interpretation uses the task text supplied in the conversation. The README structure and evidence files are an organisation choice, not a claim that the lecturer prescribed these filenames.
