# Report Writer Self-Study Notes

## Important terms

- **Audience:** the people who will read the report.
- **Purpose:** what the report should explain or help the reader decide.
- **Executive summary:** a short overview of the main findings and recommendations.
- **Findings:** important facts identified through research or data analysis.
- **Recommendations:** practical actions based on the findings.
- **Stakeholder:** a person or group affected by the work.
- **Subject-matter expert (SME):** someone with detailed knowledge of the topic.
- **KPI:** a measure used to track performance.
- **Data validation:** checking that information is complete and accurate.
- **Version control:** keeping a clear history of document changes.

## Tools

- **Microsoft Word:** formal reports, headings, tables, captions and page numbers.
- **Microsoft Excel:** cleaning, filtering, formulas, PivotTables and data summaries.
- **Power BI:** dashboards, KPIs, charts, slicers and interactive reports.
- **Markdown:** simple README files and technical notes.
- **GitHub:** file organisation, change history and collaboration.

## Simple writing process

1. Confirm the audience and purpose.
2. Collect and verify the required information.
3. Create a clear heading structure.
4. Write the first draft in plain language.
5. Check accuracy, grammar and formatting.
6. Save the final version with a clear name and commit message.
