## Notes: SSAS / Fabric / Business Objects
**SSAS (SQL Server Analysis Services)** — builds large-scale data models on the server that Power BI connects to, instead of modeling directly from a flat file. Used when data is too large/sensitive to load fully into Power BI.

**Microsoft Fabric & Data Warehouse** — a data warehouse centralises company data into one governed source; Fabric bundles data engineering, warehousing and Power BI reporting into one platform.

**Business Objects** — SAP's older enterprise BI tool, same purpose as Power BI, different vendor — still used in some legacy enterprise environments.
