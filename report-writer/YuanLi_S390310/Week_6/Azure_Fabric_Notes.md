# Azure Fabric — Basics Overview
**Yuan Li - S390310**

Microsoft Fabric is a cloud platform that bundles data engineering,
data warehousing, and Power BI reporting into one workspace, so a
report can pull directly from a shared company data warehouse instead
of a local file. For a Report Writer, the relevant piece is that a
Power BI dashboard can be built on top of Fabric-hosted data rather
than an Excel file — same DAX/report skills apply, just a different
data source.
