## Tableau vs Power BI (as I understand it so far)
| | Power BI | Tableau |
|---|---|---|
| Formula language | DAX | Calculated Fields |
| Best known for | Tight Microsoft 365 integration | Strong visual/drag-and-drop design |
| Free version | Power BI Desktop (Windows only) | Tableau Public (cross-platform, but publishes publicly) |

## Practice plan
