# Iteration-1 Shared Tool Notes - Week 5
**Yuan Li - S390310**

## JIRA
Project/issue tracking tool for managing tasks and sprints. Used it in a previous project (TCASS) to track my own task cards on the team board. Example: moving a card from To Do → In Progress → Done.

## Confluence
Team wiki/documentation tool that pairs with JIRA. Used for meeting notes, project documentation and a shared knowledge base. Example: a page documenting the team's Git workflow.

## Visio
Diagramming tool for flowcharts, process maps and org charts. Used by business analysts to map out business processes. Example: a flowchart of the booking process for NT CleanTrack.

## Draw.io (diagrams.net)
Free browser-based diagramming tool, similar to Visio. Used for quick flowcharts without needing a paid license.

## Trello
A simple kanban-board task tracker (cards and columns). Used for lightweight task management.

## Bitbucket
A Git repository hosting service, similar to GitHub. Some companies use it instead of GitHub, especially alongside JIRA/Confluence (same company, Atlassian).
